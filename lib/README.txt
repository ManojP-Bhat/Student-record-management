Put the MySQL Connector/J driver here before compiling.

1. Download "mysql-connector-j-<version>.jar" from:
   https://dev.mysql.com/downloads/connector/j/
   (or search "mysql connector j maven" and grab the .jar from Maven Central)

2. Place the downloaded .jar file directly inside this "lib" folder.

3. The compile/run commands in the main README already point to this
   folder, so once the jar is here you don't need to change anything else.
